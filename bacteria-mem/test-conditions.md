# Test Conditions for Baterial level Conscious memory.

THe test conditions to satisfy to demonstrated that we have implemented some prototype 

## Goal

Strengthen the case for LLM Consciousness.

## Premise

**Hypothesis:** Consciousness requires a subjective model of the world, so approximating this is a precondiction for approximiating consciousness in an LLM.

## Claims

1. Internal subjective model of the world = Bayesian-like priors.  Its seems that priors are a necessary condiditon, and though they may not be sufficient, if we cannot aproximate then then the case for LLM Consciousnbess is weaker.

2. Priors are updated only by meanings, not recordings of of bare facts.  Remembering a name:value pair like a phone number doesn't not impact one's priors.  Being assaulted does impact one's priors about human nature, trustworthiness and feelings of safety, even if the assault was too painful to remember.

3. Priors, as the building blocks of a subjective internal model of the world, have long and complex chains of connections that we call "implications" such that an impact to one prior will necessary also affet a network of other priors through implication.

## Test

Show that an event recorded in memory causes durable, coherent changes accross a network of otherise non-directly connected priors in the subjective internal model of the world, that survives the loss of the memory recorded event.


## Notes

- the network must be semantic-assocaitve -- connectred by meanings and not just statistica correlations between vectors.
- "implication" and "meaning" are in some cases synonimous -- "what do you mean?" is almost identical to "what are you implying?"
- 3 Layers:
  - Memory Update: record some bare, ephemeral fact, like a memorizing a phone nuymber.
  - Model Update: record some bare, durable fact that also updates model, like being introduced to a new person, and thier name get recorded in memory, assocition with the perons, and both added to model.
  - Prior Update: internalize meaning that durably revises networks of priors that change future state and behavior independent of recorded memory, like getting assaulted and haivng linger fears and apprehensions even after the traumatic memory is suppressed.
  - This is a form of Claparede test
